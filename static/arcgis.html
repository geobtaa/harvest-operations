ArcGIS Harvester

Harvests supported datasets from the configured ArcGIS Hub DCAT feeds, normalizes their metadata, and prepares full outputs, upload deltas, registry snapshots, and a dashboard report.

Documentation ArcGIS report archive

Before you run

Update the input CSV files by running the Dashboard Triage.

What a full run writes

  • Dated primary and distribution CSVs in outputs/.
  • A dated run report in reports/arcgis/.
  • Upload deltas in outputs/to_upload/.
  • Updated primary and distribution snapshots in registry/.

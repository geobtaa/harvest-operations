CKAN Curation Pipeline

This dashboard runs ckan_curation_pipeline for selected CKAN or PortalJS datasets. It reuses the CKAN harvester for draft metadata, pauses for review, downloads the selected GeoJSON resources, and builds the same curated artifacts as the ArcGIS Hub and Socrata workflows.

The public portal and CKAN API may use different hosts. Each package can pin a resource UUID, preventing an ambiguous or newly added download from silently changing the curated source.

Socrata Curation Pipeline

This browser runs the staged socrata_curation_pipeline. It selects datasets from a portal's DCAT catalog, reuses the Socrata harvester for draft metadata, pauses for review, and builds the same curated artifacts as the ArcGIS workflow.

Large datasets are fetched as ordered SODA2 GeoJSON pages with explicit limits, source-revision checks, and row-count checks. Set the city abbreviation and download year once per job; each record then needs only a filename theme. Jobs come from curation/jobs/socrata/*.yaml; the template is excluded from the runnable list.
